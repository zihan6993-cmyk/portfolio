# Zihan Zhang — Portfolio

A static portfolio website featuring six spatial design projects, an interactive image trail, original project page readers, CV sections and contact information.

## Preview
Open `index.html` in a browser. No build or dependencies are required.

## GitHub Pages
In Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
